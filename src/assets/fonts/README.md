# Fonts

Both fonts are self-hosted (Latin subset, variable weight) and licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org).

- **Atkinson Hyperlegible Next** by the Braille Institute of America. Used for all text. It was designed so
  that similar letters (I, l, 1; O, 0) are hard to confuse.
- **Big Shoulders** by Patric King / xotype for the City of Chicago. Used for the large counter and view titles.

The files come from the Fontsource packages `@fontsource-variable/atkinson-hyperlegible-next` and
`@fontsource-variable/big-shoulders`.
